# ✅ To-Do List / Task Manager

A simple GUI-based To-Do List application developed using Python and Tkinter for task management and productivity.

## 🚀 Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Save tasks permanently using file handling
- User-friendly GUI

## 🛠 Technologies Used

- Python
- Tkinter
- File Handling
- OS Module
